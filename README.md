# Zarettiphone

Site estático para a loja Zarettiphone, em Curitiba (PR).

## Publicar no GitHub Pages

Envie `index.html` e a pasta `assets` para a raiz do repositório. O arquivo inicial e as imagens devem permanecer lado a lado como estão neste ZIP. Os caminhos das imagens são relativos, então funcionam também quando o GitHub Pages publica o site em uma subpasta com o nome do repositório.

As quatro imagens usadas estão em `assets/images/`; nenhuma imagem depende de hospedagem externa.

Para editar o site, altere `index.html`. Os botões de contato apontam para https://instagram.com/zarettiphone/. A disponibilidade dos aparelhos deve ser confirmada com a loja.
